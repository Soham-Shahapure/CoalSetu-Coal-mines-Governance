# Manager Dashboard Section Navigation

Added a responsive section-navigation row below the Manager dashboard heading. Buttons smoothly scroll to:

- Mine Profiles
- Risk & Details
- Corrective Actions
- Recent Observations
- Score Method

The buttons follow the existing sky-blue/white visual language, distribute across the available width, and wrap into a compact grid on smaller screens. Section targets use scroll offsets so headings remain visible after navigation. No APIs, business logic, persistence, or role permissions were changed.
